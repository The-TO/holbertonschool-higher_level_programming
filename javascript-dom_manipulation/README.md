# JavaScript - DOM Manipulation

Scripts that manipulate the DOM of a web page: selecting elements,
updating styles, classes and content, creating elements, listening
to user events and fetching data from APIs with the Fetch API.

All scripts run in Chrome (57.0+) and are semistandard compliant.

## Files

| File | Description |
| --- | --- |
| `0-script.js` | Sets the `header` text color to red |
| `1-script.js` | Turns the `header` red when `#red_header` is clicked |
| `2-script.js` | Adds the class `red` to `header` on click |
| `3-script.js` | Toggles `header` between classes `red` and `green` |
| `4-script.js` | Adds a new `li` to `ul.my_list` on click |
| `5-script.js` | Updates the `header` text on click |
| `6-script.js` | Fetches and displays a Star Wars character name |
| `7-script.js` | Fetches and lists all Star Wars movie titles |
| `8-script.js` | Fetches "hello" in French and displays it |

## Usage

Open any `N-main.html` file in Chrome to test the matching script.
